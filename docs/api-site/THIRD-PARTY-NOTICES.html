    ProvostXInference is MIT licensed (see LICENSE). It incorporates the following third-party components.

    llama.cpp / ggml

    • Used for: the entire native inference core — GGUF model loading, tokenization, batched decoding, KV cache management, vision (MTMD), embeddings, and the Metal/CUDA/ Vulkan/CPU backend layer
    • Source: https://github.com/ggml-org/llama.cpp (vendored as a git submodule under llama.cpp/)
    • License: MIT — the full license text ships in llama.cpp/LICENSE (Copyright (c) 2023-2026 The ggml authors)
    • Linking: statically linked into libpvxinference (BUILD_SHARED_LIBS=OFF). Upstream llama.cpp is used PRISTINE — no local patches, no fork.

    Platform acceleration libraries

    • Apple Metal / Accelerate / BLAS (macOS builds) and CUDA / Vulkan SDKs (Linux/Windows builds) are platform libraries provided by the OS vendor and are not redistributed by this project; they are linked from the user's installed SDKs.

    C# bindings

    The csharp/ project is a dependency-free .NET 8 class library — it P/Invokes the native library directly and takes no third-party NuGet packages.
