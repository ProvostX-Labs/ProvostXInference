    Class DecisionSessionFactory

    Creates DecisionSessions for a judge model file: builds the ORT session options (full graph optimization, matching the training runtime) and walks the parsed ExecutionProviderChain in preference order (LLM-10 per-OS chains). EP FALLBACK RULE: a provider that fails to initialize (not bundled, driver/library problems, unsupported ops) degrades to the next entry — CPU is always the terminal fallback and is the only provider REQUIRED to work. The session's ACTUALLY-active provider is read back from the runtime (a silent ORT fallback to CPU counts as a fallback, not as GPU) and recorded so /pvx/health `active_execution_provider` is truthful. One factory per host; thread-safe (stateless beyond the injected option applier).

    Initialize a session for modelPath, trying each configured provider in chain order (per-provider option presets first, plain append fallback second).
