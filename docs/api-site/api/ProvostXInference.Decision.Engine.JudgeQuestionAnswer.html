    Class JudgeQuestionAnswer

    ONE raw model answer for one Jev question (session decode → response mapper boundary). RAW semantics: the model's argmax choice / expected score / noul probability — NO risk-escalation rule applied (the escalation owner is JudgeVerdictMapper on the enriched arms; the raw wire stays raw). Field populations per type: choice → Choice + Confidence + Probabilities; score → Score + Confidence + Probabilities (level-index keyed) + Legend; noul → Noul. Pure data.
