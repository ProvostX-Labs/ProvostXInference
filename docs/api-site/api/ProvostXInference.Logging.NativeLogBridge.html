    Class NativeLogBridge

    Bridges native C-level logging (pvx_set_log_callback) to a managed callback. Encapsulated in the Inference layer — no dependency on LLM or Core loggers. The caller provides an Action<int,string,string> that forwards to whatever logger they have (LLM's ServerLogger, Core's Logger, console, etc.). Per-handle dispatch (BL-02): the pvx_set_log_* entry points are invoked on the ENGINE'S OWN dispatch tables (resolved via the active per-handle dispatch route) — never the global static route — so logging state lives in the specialist module that owns the model. The delegate thunk itself must still be pinned for the process lifetime (the native side stores the raw function pointer).
