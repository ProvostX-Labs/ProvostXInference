    Interfaces

    IChunkWallClock

    Wall-clock seam for per-chunk prefill timing (INF BL-33). The native prompt commit is synchronous, so the wall measured around it IS the chunk wall on whatever backend is compiled in (metal / cuda / vulkan / cpu — backend-independent by construction); the seam exists so tests can script timings instead of sleeping.

    ILoraAdapter

    ABI v8 (wave 3, feature 9): a loaded LoRA adapter (opaque native handle). Loaded against ONE model (arch-matched, typed on mismatch); attached to contexts via IInferenceContext.SetAdapters. Weights-surface modifier: KV-neutral, attach/detach mid-conversation without rewind.

    IPrefillStallDetector

    Typed stall detector over per-chunk prefill wall timings (INF BL-33). Stateful across the chunks of one prefill: it maintains the rolling baseline itself.

    ISpeculationSuspender

    Runtime suspension of the speculative helper (draft/ngram) on the owning executor stack — the real native wiring for the stall-safe prefill ladder's DraftDisabledRetry rung (INF BL-33b). Implementations must be idempotent (suspending with no active session is a no-op, mirroring the native pvx_executor_spec_free contract) and must not throw when the helper is already disabled.

    IStallRecoveryLadder

    Facade view of the stall-recovery ladder (INF BL-33): owns the configured step order and the retry budget; returns the step for a given 0-based retry attempt and fails closed when the budget is exhausted (the caller is expected to throw the typed unrecovered error then — the ladder itself never invents steps). Surfaced behind the Engines facade (StallWatchdogOps.CreateRecoveryLadder) so callers never touch the Implementation namespace.

    IStandardExecutor

    ITtsSession

    ABI v8 (wave 3, feature 7): a TTS session — a SEPARATE decode context on the backbone speech model plus a gen-audio mmproj. Never entangled with a conversation context (KV-neutral by construction). Capability-truthful: creation against a mmproj without a gen-audio pipeline throws typed. Determinism: identical (text, request.Seed) pairs replay byte-identically.
