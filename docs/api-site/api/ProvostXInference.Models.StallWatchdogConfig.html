    Class StallWatchdogConfig

    Configuration for the engine-level stall-safe prefill watchdog (stall_watchdog config section; INF BL-33). Defaults follow the owner decision: multiplier 5 over the rolling median chunk wall, 3 retries, the full four-step recovery ladder.
