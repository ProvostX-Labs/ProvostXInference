    EnableSpeculation(SpeculativeConfig)

    Enable a speculative session on this executor. Fail-closed: a config that cannot be honored (missing/unloadable draft model, missing capability, wrong vocab family) throws InferenceException naming the boundary — never a silent fallback to non-spec generation. Mode Off clears any existing session (disable).

    GenerateSpeculative(SamplingConfig?, int, Action<int>?)

    Speculative generation over the executor's current prompt+history (draft → verify → commit until EOG or maxTokens). Returns the generated token ids in order; each token is also streamed to onToken when given. Requires an enabled session — typed error otherwise (never a silent non-spec run). Token-exact vs the plain Prompt/Infer/Sample loop for identical sampling params.
