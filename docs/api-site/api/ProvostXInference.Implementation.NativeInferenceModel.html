    Class NativeInferenceModel

    CreateGrammarFromJsonSchema(string, string?)

    ABI v7: JSON Schema → GBNF via the native pattern-port of the vendored converter (product code never links the vendored tree). The produced GBNF is compiled by the existing grammar chain; the provenance label marks the grammar as schema-derived. Fail-closed: native typed refusals (parse position / unsupported keyword) map to InferenceException through the standard channel — never a loose grammar. The out_error buffer is freed on every path (it is only set on failure; freeing it in the finally keeps the throw path leak-free).
