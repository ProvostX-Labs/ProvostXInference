    Namespace ProvostXInference.Engines

    Classes

    DecisionEngineOps

    Decision lane ops over an existing DecisionSession (loaded by the factory through IDecisionSessionFactory).

    DecisionEngineRequest

    Contract for an ONNX decision (judge) engine on the managed ORT lane: model path, tokenizer JSON, judge sequence-spec JSON, execution-provider chain (raw string, LLM-10 format; null = OS default), optional numerics gate.

    DecisionEngineRequestBuilder

    Fluent builder for DecisionEngineRequest (ONNX judge lane). Build() yields a VALIDATED request (fail-closed).

    EncoderEngineOps

    Encoder lane ops: wraps the vision encoder + backing model (see interface).

    EncoderEngineRequest

    Contract for a vision ENCODER engine: a GGUF model (for its vocabulary/ tokenizer context) plus a REQUIRED mmproj projector. The engine's primary lane is image embedding; generative GGUF ops are NOT exposed on this kind.

    EncoderEngineRequestBuilder

    Fluent builder for EncoderEngineRequest (vision encoder lane: GGUF model + REQUIRED mmproj). Build() yields a VALIDATED request.

    EngineLogging

    Facade view of the native logging bridge (owner black-box directive 2026-10-19): native C-level log setup is a process-wide facade concern (the pvx_set_log_* entry points dispatch on the ACTIVE engine's tables), so callers configure it here instead of reaching into the Logging namespace. Pure delegation — identical semantics, facade-only surface.

    EngineMaintenance

    Facade view of the offline engine-maintenance utilities (owner black-box directive 2026-10-19): file-level operations that need NO loaded engine object but ARE engine-bound (they dispatch on the ACTIVE engine's per-handle tables). Currently: GGUF tokenizer-metadata repair (EOG/special token fixup — weights stream-copied byte-for-byte, metadata rewritten). Pure delegation to the Implementation layer — callers never leave the facade surface.

    EngineRequest

    The typed engine CONTRACT base: everything a caller must tell Inference to get an IInferenceEngine. Derived records add lane-specific parameters. Validate() is fail-closed — any invalid field throws InvalidEngineRequestException before a backend is ever touched.

    GgufEngineOps

    GGUF lane ops implementation over the wrapper-layer graph. Holds the model, the live context (created from the request's context settings), and the pool (lazily created on first LeaseConversation()). Disposal flows outward-in via the owning InferenceEngine.

    GgufEngineRequest

    Contract for a GGUF generative engine on the native llama.cpp backend: model path, optional vision projector (mmproj) sidecar, optional speculative draft-model sidecar, and the full native load knob set (BL-02 engine matrix, GPU layers, threads, flash attention, KV type, reasoning markers) plus context sizing. Knobs are load-time; live knobs live on the engine object.

    GgufEngineRequestBuilder

    Fluent builder for GgufEngineRequest. Build() yields a VALIDATED request (fail-closed); Create(IInferenceEngineFactory) builds + factory-creates an engine in one step.

    GgufModelLoader

    Production IGgufModelLoader: thin wrapper over the native wrapper-layer factories (Load(ModelConfig) + LoadVisionEncoder(string)). No state, no fallback.

    InferenceEngine

    Facade implementation: created UNLOADED by InferenceEngineFactory, loaded on Initialize() per kind, torn down on Dispose (ops first, then backend). All deps constructor-injected; no static state.

    InferenceEngineBuilder

    Fluent entry point of the engine-object contract: 
    var engine = InferenceEngineBuilder.Gguf("/path/model.gguf")
    .WithMmproj("/path/mmproj.gguf").WithGpuLayers(99)
    .Build();                    // → validated GgufEngineRequest
engine.Create(factory).Initialize();   // → live IInferenceEngine
    No static mutable state — the builder is a local, disposable scratch record.

    InferenceEngineFactory

    Default factory (composition root of the facade): native GGUF loading via GgufModelLoader (thin seam over the wrapper-layer static factory), decision loading via the existing IDecisionSessionFactory lane. No static mutable state.

    StallWatchdogOps

    Facade factory for the stall-watchdog helper family (INF BL-33, owner black-box directive 2026-10-19): the rolling-median detector, the recovery ladder and the production wall clock are ENGINE-LEVEL utilities (backend-independent, pure managed) — but callers must consume them through the facade surface, never the Implementation namespace. This static factory is the sole construction seam; the returned types are the Abstractions interfaces. Fail-closed: a null/invalid config throws (the underlying helpers validate in their constructors).

    Interfaces

    IDecisionEngineOps

    Decision (ONNX judge) lane ops view: batch judging on the ORT session with truthful active-provider reporting, plus the tokenizer/spec the caller needs to build records. Wraps DecisionSession; adds nothing native.

    IEncoderEngineOps

    Encoder lane ops view: image embedding through the mmproj projector mounted on the GGUF model's context. Text embeddings are reachable via the Gguf-style model context; this view keeps the vision lane honest and minimal.

    IGgufEngineOps

    GGUF lane ops view: the full native llama.cpp surface as properties/methods — context management, KV-cache operations, sampling knobs, speculative knobs. Wraps the existing wrapper-layer graph (model → context → pool → conversation); the raw abstractions stay reachable for advanced callers.

    IGgufModelLoader

    Testability seam over the native GGUF loader: the engine factory depends on THIS interface, not on NativeInferenceModel's static factory, so the facade is unit-testable without a native image.

    IInferenceEngine

    The SOLE caller-facing object of Inference's world: one loaded backend (GGUF llama.cpp, ONNX decision, or vision encoder) behind a typed facade with lifecycle, inference ops, context management, KV-cache ops, and every knob as a property. Callers (e.g. ProvostXLLM) hold an array of these and route requests by Kind/ModelPath.

    IInferenceEngineFactory

    Resolves a validated EngineRequest into an UNLOADED IInferenceEngine. Constructor-injected backend seams keep this unit-testable without native images.

    Enums

    EngineKind

    Which backend lane an IInferenceEngine serves. One engine object per lane; the facade routes ops views by this kind (fail-closed on mismatch).
