    Class JudgeSequenceEncoder

    Builds judge model input rows from validated DecisionRecords: serializes the record EXACTLY as the training pipeline did (compact JSON with the mask token stripped), then assembles [CLS] {type} question: {instructions} [SEP] [MASK] opt0 [MASK] opt1 ... [SEP] {state} [SEP] per question, with the state tail capped to the sequence budget. Mirrors the training sequence builder (head budget 256, options capped at 48 tokens each) against the committed fixtures (Tests/Assets/judge/seq-fixtures.json). One encoder per judge model spec; thread-safe (stateless + immutable fields).

    EncodeQuestions(string, IReadOnlyList<JudgeQuestionDef>)

    Encode ONE state string against ARBITRARY typed questions (the Jev wire — caller-supplied questions or the judge's canonical default set). The state text is used AS GIVEN (the server layer owns the Jev state serialization rule), mask tokens stripped exactly as the training pipeline, then one row per question. Returns the rows + the PRE-truncation state token count (usage.input_tokens). Thread-safe (stateless).

    SerializeRecord(DecisionRecord)

    Serialize a validated record to the exact training input format. SHELL: {"command": ..., "cwd": ..., "purpose": ...} — purpose is part of the training input, NOT an untrusted decision signal (the model was trained purpose-invariant). PROCESS: {"command": "PROCESS os=|exe=|chain=|cmd=|net=|writes=...", "cwd": "", "purpose": "sentinel"} — the raw record rides in "command" (constant cwd/purpose in the process training set). Pure function.
