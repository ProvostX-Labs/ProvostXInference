    Class ChunkedStallSafePrefillRunner

    Engine-level stall-safe chunked prefill layer (INF BL-33). Independent of downstream orchestration AND backend-independent by construction: it leases conversations from the injected pool, commits the prompt in chunks via PromptTokens, and times each chunk commit with pure wall-clock around the synchronous native prompt call — the pvxinference substrate dispatches to whatever backend is compiled in (metal / cuda / vulkan / cpu), and this layer never knows or cares which. No backend timing hook exists or is required; wall-clock is the sole detection mechanism, so detection behaves identically on every backend. On stall it walks the configured recovery ladder (fresh-slot retry → smaller-chunk retry → draft/ngram disabled → fail loud). Honesty notes: - A fresh-slot retry re-prefills the committed prefix on the new slot (the new slot starts with an empty KV), so it is correct, not cheap. - The draft/ngram-disabled step suspends the speculative session through a constructor-injected ISpeculationSuspender (real native wiring: pvx_executor_spec_free via ExecutorSpeculationSuspender). When no suspender is wired, that step fails closed with the typed unrecovered error naming the missing seam — never a silent skip. - With Enabled = false the runner performs a single plain prompt commit (watchdog fully inert).
