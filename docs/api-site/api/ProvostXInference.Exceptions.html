    Namespace ProvostXInference.Exceptions

    Classes

    EngineKindMismatchException

    Fail-closed typed error for accessing an ops view of the wrong kind (e.g. engine.Decision on a Gguf engine). The facade never hands out a null view — it refuses.

    InferenceException

    Thrown when a native ProvostXInference call returns an error code. Base of the typed-error family (engine contract, LDC audit 2026-10-17).

    InvalidEngineRequestException

    Fail-closed typed error for an invalid engine contract (bad/missing path, out-of-range knob, wrong-kind field). Thrown BEFORE any backend is touched.

    PrefillStallUnrecoveredException

    Fail-loud terminal outcome of the stall-safe prefill recovery ladder (INF BL-33): a prefill chunk kept stalling past the configured retries. Carries the evidence (chunk index, wall, baseline, steps attempted) so the failure is diagnosable — never a silent hang or a quiet degradation.
