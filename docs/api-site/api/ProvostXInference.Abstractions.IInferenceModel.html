    PartialRewindSupported

    Whether the model's memory supports partial-sequence truncation (rewind to an arbitrary token boundary). Hybrid architectures (attention + recurrent layers, e.g. qwen35/qwen3next) and purely recurrent architectures CANNOT: their recurrent state is not preserved per token, so the native memory refuses partial seq_rm ranges (PVX_ERR_REWIND_UNSUPPORTED). KV retention / prefix-cache reuse via partial rewinds must be disabled for such models. Dense attention memories — including M-RoPE ones — support it.

    SpeculativeCapabilities

    Speculative-decoding self-report (INF BL-05): the engine's supported-types list for THIS loaded model (SpeculativeType bitset derived from GGUF metadata: arch + nextn/MTP tensor presence). The LLM/dashboard offers exactly the reported types for sequential mode. No default: a fake or adapter must report honestly, never silently overpromise.
