    Namespace ProvostXInference.Decision.Abstractions

    Interfaces

    IDecisionHeaderReader

    Decision-model file validation seam (load state machine step). A REAL protobuf scan of the ONNX ModelProto wire (ir_version, graph IO signature names, opset_import presence) — long initializers are skipped by seek, so a 500MB+ model validates in milliseconds. Any structural violation throws — the load state machine maps that to fail-closed model_invalid before any session init is attempted.

    IDecisionSessionFactory

    Creates DecisionSessions for a decision (judge) model file: builds the ORT session options (full graph optimization, matching the training runtime) and walks the parsed ExecutionProviderChain in preference order. EP FALLBACK RULE: a provider that fails to initialize degrades to the next entry — CPU is always the terminal fallback and is the only provider REQUIRED to work. The session's ACTUALLY-active provider is recorded so health reporting is truthful. One factory per host; thread-safe.

    IExecutionProviderDefaultSource

    Per-OS DEFAULT execution-provider chain for decision models: applied when a model configures NO explicit execution_provider. Injected so tests can pin the OS.
