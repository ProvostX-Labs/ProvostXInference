    Enum PrefillRecoveryStep

    Recovery-ladder step executed after a detected prefill stall (stall-safe prefill layer, INF BL-33). Ordered from cheapest to fail-loud; the ladder always terminates in FailLoud so a persistently stalling prefill never spins silently.
    Namespace: ProvostXInference.Models
    Assembly: ProvostXInference.dll
    Syntax
    public enum PrefillRecoveryStep

    Fields

    Name Description
    DraftDisabledRetry Retry the stalled chunk with draft/ngram speculative helpers disabled via the constructor-injected suspension hook.
    FailLoud Fail loud: throw a typed PrefillStallUnrecoveredException naming the chunk, the timings, and the ladder steps attempted.
    FreshSlotRetry Return the current conversation to the pool and continue on a freshly leased slot (replays the committed prefix first).
    SmallerChunkRetry Retry the stalled chunk with the chunk size halved (floor: MinChunkSizeTokens).
