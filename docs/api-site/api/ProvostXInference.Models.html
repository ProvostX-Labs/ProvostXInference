    Namespace ProvostXInference.Models

    Classes

    AudioChunk

    ABI v8 (wave 3, feature 6): one raw PCM audio clip for prompt-with-audio. Mono F32 samples at the projector's NATIVE sample rate (probe via IInferenceModel.AudioSampleRate; product code never resamples — a rate mismatch is the caller's typed failure). One clip per record.

    BackendInfo

    Snapshot of backend probe results.

    ContextConfig

    User-facing context configuration.

    EngineStats

    ABI v8 (wave 3, feature 12): copy-out stats snapshot of one lane (executor or conversation). Spec counters mirror the spec telemetry (0/0 when no session is active); rejected drafts derive as drafted-accepted.

    EngineTelemetry

    ABI v9 (per-engine telemetry, owner order 2026-10-22): MODEL-aggregate snapshot — the roll-up of every executor/conversation lane on ONE engine instance (never process-wide). Rates (tok/s etc.) are derived by the caller between two snapshots; the engine stays stateless. Counters never hide failures: rejected spec drafts derive as Drafted - Accepted.

    KvOverride

    ModelConfig

    User-facing model configuration (not blittable — converted to PvxModelParams internally).

    NgramConfig

    n-gram speculative-dcoding knobs (ABI v6). Active iff the speculative mode is an n-gram mode; zero values select the per-mode native defaults. Sentinel discipline mirrors the rest of SpeculativeConfig: the config is blitted to pvx_ngram_params_t at the native boundary.

    PrefillStallVerdict

    Typed result of one stall-detector observation (INF BL-33). Immutable; carries the evidence so callers can log or fail with real numbers instead of a bare boolean.

    PvxEngineSelector

    Validates the ModelConfig engine field against the 5-product engine matrix: result object over (engine id, OS probe) — unknown ids and wrong-OS selections fail closed with a typed error; no default engine guessing here. Stateless utility — no mutable state.

    PvxEngineSpec

    A selected per-model engine: a validated (engine, OS) specialization from the 5-product matrix — the file-name contract lives exclusively in the Interop policy/resolver layer (names in ONE place). The ModelConfig engine field selects WHICH specialist dylib runs for this model; the resolver rejects unknown engines and wrong-OS selections fail-closed.

    PvxEngineValidation

    Outcome of engine-selection validation: exactly one of a validated spec or a typed fail-closed error (never both, never a guessed default).

    SamplingConfig

    User-facing sampling configuration.

    SpeculationStats

    Spec-session acceptance telemetry for ONE speculative session (executor or pooled conversation; ABI v7 adds the conversation lane): cumulative drafted/accepted token counters since session start. Zero/zero when no session is active — counters never hide rejections.

    SpeculativeCapabilities

    The engine's self-reported speculative capabilities for ONE loaded model: a supported-types list (SpeculativeType bitset), not booleans. A report of None means the model supports no native speculative type — the second draft model (SpeculativeMode.Draft with a user-provided draft model) remains the available option whenever DraftSimple is reported.

    SpeculativeConfig

    StallWatchdogConfig

    Configuration for the engine-level stall-safe prefill watchdog (stall_watchdog config section; INF BL-33). Defaults follow the owner decision: multiplier 5 over the rolling median chunk wall, 3 retries, the full four-step recovery ladder.

    TtsRequest

    ABI v8 (wave 3, feature 7): TTS knobs. Zero values select the per-model upstream defaults (native mtmd_gen_inp_default); Seed == uint.MaxValue selects a random draw (fixed seeds replay byte-identically).

    TtsResult

    TTS generation result: raw PCM F32 mono at the pipeline rate.

    Enums

    KvType

    PoolingType

    PrefillRecoveryStep

    Recovery-ladder step executed after a detected prefill stall (stall-safe prefill layer, INF BL-33). Ordered from cheapest to fail-loud; the ladder always terminates in FailLoud so a persistently stalling prefill never spins silently.

    PvxEngineSelectionError

    Typed failure of engine-selection validation (fail-closed contract — every invalid pair or unknown id resolves to one of these, never to a guessed default).

    SpeculativeMode

    Speculative-decoding mode, values mirror pvx_spec_mode_t exactly. Fail-closed rule: a configured path that cannot be honored (missing/unloadable draft model, missing capability, wrong vocab family) is a typed error naming the boundary — never a silent fallback to non-spec generation.

    SpeculativeType

    Supported speculative-decoding types, mirrored from the llama.cpp speculative enum via the engine's self-report (PVX_SPEC_TYPE_* bits). The ENGINE decides what the loaded MODEL supports — query IInferenceModel.SpeculativeCapabilities per model load and offer exactly these types for sequential mode; never assume.
