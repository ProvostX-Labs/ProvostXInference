    Class PrefillStallUnrecoveredException

    Fail-loud terminal outcome of the stall-safe prefill recovery ladder (INF BL-33): a prefill chunk kept stalling past the configured retries. Carries the evidence (chunk index, wall, baseline, steps attempted) so the failure is diagnosable — never a silent hang or a quiet degradation.
