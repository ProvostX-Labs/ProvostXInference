    ChunkedStallSafePrefillRunner

    Engine-level stall-safe chunked prefill layer (INF BL-33). Independent of downstream orchestration AND backend-independent by construction: it leases conversations from the injected pool, commits the prompt in chunks via PromptTokens, and times each chunk commit with pure wall-clock around the synchronous native prompt call — the pvxinference substrate dispatches to whatever backend is compiled in (metal / cuda / vulkan / cpu), and this layer never knows or cares which. No backend timing hook exists or is required; wall-clock is the sole detection mechanism, so detection behaves identically on every backend. On stall it walks the configured recovery ladder (fresh-slot retry → smaller-chunk retry → draft/ngram disabled → fail loud). Honesty notes: - A fresh-slot retry re-prefills the committed prefix on the new slot (the new slot starts with an empty KV), so it is correct, not cheap. - The draft/ngram-disabled step suspends the speculative session through a constructor-injected ISpeculationSuspender (real native wiring: pvx_executor_spec_free via ExecutorSpeculationSuspender). When no suspender is wired, that step fails closed with the typed unrecovered error naming the missing seam — never a silent skip. - With Enabled = false the runner performs a single plain prompt commit (watchdog fully inert).

    ExecutorSpeculationSuspender

    Runtime draft/ngram suspension backed by the executor's native speculative-session teardown (pvx_executor_spec_free; INF BL-33b). Idempotent by construction — the native teardown is already idempotent and the suspension is recorded so a second Suspend is a managed no-op.

    GgufMetadataRepair

    GGUF tokenizer-metadata repair (owner 2026-10-06): some HuggingFace GGUFs omit the EOS token from tokenizer.ggml.special_eog_ids — the engine's native EOS stop then never fires and generation runs past end-of-turn. The native pvx_repair_eog_metadata rewrites the METADATA ONLY (weights stream-copied byte-for-byte); this is the public managed facade over it. Dispatches on the ACTIVE engine's per-handle dispatch tables (BL-02).

    NativeConversation

    Wraps a leased pvx_conversation_t. Does NOT own the handle — the pool does. Dispose() returns it to the pool if not already returned. All calls dispatch on the OWNING ENGINE's per-handle tables (carried from the pool at lease).

    NativeConversationPool

    Wraps a native pvx_pool_t. All calls dispatch on the OWNING ENGINE's per-handle tables (flowed from the context's model); a leased conversation carries the same tables for its own calls.

    NativeConversationSpecSession

    Speculative session bound to ONE pooled conversation (ABI v7, feature 5): enable/generate/stats over pvx_conversation_spec_*, with the active-config mirror kept honest by routing every mutation through Enable/Disable below (same discipline as the executor lane). The native pool-return/teardown paths free the session natively; ProvostXInference.Implementation.NativeConversationSpecSession.OnReturned() clears the managed mirror so it can never report a phantom session.

    PvxDefaultEngineSelector

    Platform default engine selection — used when the model config leaves the engine field unset: macOS resolves to the metal specialist; Windows/Linux prefer cuda when its specialist file ships, else vulkan, else the cpu engine (every platform can build a CPU specialist); fail-closed (typed error, no silent fallback) when none is installed. The OS identity is constructor-injected (same probe family the selector matrix consults — no hidden environment dependence). Stateless utility — no mutable state.

    RollingPrefillStallDetector

    Rolling-median stall detector (INF BL-33). A chunk is a stall when its wall exceeds GapMultiplier × the rolling median of the recent baseline window. The detector is silent (never a stall) until the baseline holds at least MinBaselineSamples clean observations — the first chunks of a prefill cannot be judged against an empty baseline.

    StallRecoveryLadder

    Recovery ladder for the stall-safe prefill layer (INF BL-33). Owns the configured step order and the retry budget; returns the step for a given 0-based retry attempt and fails closed when the budget is exhausted (the caller is expected to throw the typed unrecovered error then — the ladder itself never invents steps).

    SystemChunkWallClock

    Production wall clock backed by the injected TimeProvider (constructor injection, no statics — INF BL-33).
