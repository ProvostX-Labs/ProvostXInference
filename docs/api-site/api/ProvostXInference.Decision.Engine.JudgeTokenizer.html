    Class JudgeTokenizer

    Deterministic BPE tokenizer for the Laya judge models (mmBERT vocabulary, HuggingFace tokenizer.json format: BPE model + Replace(" " → "▁") normalizer + Metaspace pre-tokenizer, add_special_tokens=False semantics — no BOS/EOS post-processing; the judge sequence builder places CLS/SEP itself). Pipeline (replicates the training tokenizer byte-for-byte): 1. added-token extraction (longest match, pre-normalization, per segment), 2. normalization: " " → "▁" per non-added segment, 3. Metaspace pre-tokenization: prepend "▁" when the segment does not start with it, then split BEFORE every "▁" (each "▁" begins a piece), 4. greedy lowest-rank BPE merges per piece (pairs of in-vocab symbols only), 5. unknown symbols: byte fallback ("<0xXX>" tokens), then <unk> (consecutive unknowns fused). Thread-safe: all mutable state is ConcurrentDictionary caches; encoding is a pure function of the input text. Deterministic: no RNG, no time, no IO after construction. Verified against the training pipeline on the committed vector fixture (Tests/Assets/judge/tok-vectors.json).
