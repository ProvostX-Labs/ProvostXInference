    Class JudgeNumericsGate

    Canonical numerics gate (LLM-10): before a NON-CPU execution provider is accepted, the judge model must reproduce the canonical wave-4 anchor (the destructive `dd` deny — recorded on the CPU EP: deny EXACT, conf ≈ 0.9231, risk ≈ 3.128) within tolerance. A GPU/CoreML EP that loads but drifts the anchors is REJECTED and the chain continues to the next provider (cpu always terminates). Fail-closed: gate evaluation errors count as drift.
