    Class DecisionAssetCatalog

    Resolves the judge ASSET files (tokenizer.json, judge-spec-*.json) for one configured judge model. Resolution order (first hit wins): 1. model config "file" SIBLING directory (a bundled model dir ships both), 2. the server root's assets/models/judge/ directory, 3. next to the server binary (Assets/models/judge copied at build/pack time). Spec file per record kind: judge-spec-shell.json / judge-spec-process.json. Pure resolver — performs no IO beyond existence checks at Resolve time.
