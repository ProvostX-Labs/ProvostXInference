    Engine

    Engine selection (per-model config knob, BL-02): WHICH specialist dylib serves this model — one of the 5-product matrix ids ("metal" = macOS only; "cuda"/"vulkan" = Windows/Linux). Fail-closed: unknown engine ids and wrong-OS selections throw at load time; different models in one process may select different specialists (per-handle dispatch routes each model's calls onto its own image). Null = platform default (macOS: metal; elsewhere: cuda when installed, else vulkan).
