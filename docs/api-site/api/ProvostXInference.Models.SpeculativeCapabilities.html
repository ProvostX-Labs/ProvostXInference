    Class SpeculativeCapabilities

    The engine's self-reported speculative capabilities for ONE loaded model: a supported-types list (SpeculativeType bitset), not booleans. A report of None means the model supports no native speculative type — the second draft model (SpeculativeMode.Draft with a user-provided draft model) remains the available option whenever DraftSimple is reported.
