    Enum SpeculativeMode

    Speculative-decoding mode, values mirror pvx_spec_mode_t exactly. Fail-closed rule: a configured path that cannot be honored (missing/unloadable draft model, missing capability, wrong vocab family) is a typed error naming the boundary — never a silent fallback to non-spec generation.
